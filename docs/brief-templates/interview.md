# 面试 brief 模板

> 面试开始前把本文件内容（按你的情况改好）粘进 `~/AudioGateway/brief.md`。
> 参谋的话术质量上限就是 brief 的细致程度——写进来的事实才会被引用；
> 会议中途改动会自动热重载，无需重启。

场景：我是应聘者，面试【公司名】的【岗位名】。

## 面试对象

- 公司：【公司名、业务方向、你了解到的近况（融资/新产品/技术博客要点）】
- 岗位：【岗位名 + JD 里的关键要求，逐条列出（参谋会拿你的经历去对齐）】
- 面试轮次与面试官：【一面/终面；技术面试官/HR/部门负责人】

## 我的核心事实（简历要点）

- 经验：【年限 + 技术栈，如 8 年 Java/Go 后端】
- 现职：【公司类型、职位、团队规模、是否仍写代码】
- 代表项目：【1-3 个，各一句话讲清"做了什么+量化结果"——
  压力追问时参谋会用它们举证】
- 自我介绍开场（可直接念的版本）：
  【两三句：年限+现职角色+最拿得出手的一件事】

## 高频问题口径（每条都写"要说什么"，参谋照此给话术）

- 离职理由：【正面口径，如"想做自研产品、追求更大技术挑战"——
  绝不说前公司坏话】
- 弱点：【弱点 + 正在做的改善行动，一定成对出现】
- 薪资：期望【X 万】，底线【Y 万】，低于底线不当场答应，
  争取【RSU/签字费/年终】等综合待遇补差
- 在职状态：【在职/离职；提辞呈后 N 周可入职；他社选考进行中，
  不承诺独家辞退】

## 逆问预备（"何か質問はありますか"时用）

1. 【如：团队规模与技术栈演进计划】
2. 【如：入职后前三个月的期待】
